## 3. 数据与安全边界

- **不升 schemaVersion 3**。重开复用 `revision(kind='revert', reopen=true)`，不新增 `REVISION_KIND`；旧 v0.7 读 v0.8 账本不会因为未知枚举报错。
- 决策新增可选字段：`reopenCount` / `reopenedAt` / `previousChoice` / `lastReopenRevisionId`；旧账本缺省可读。
- 回退事务：
  1. 校验 `expectedBookUpdatedAt`；
  2. `planRewind` 校验 hash / 锚点 / 选项；
  3. 存 `rewinds/<id>.md` + `.json`；
  4. 截断正文；
  5. `mutateBookData` 内倒序撤 canon/义务、段落 `reverted`、后续决策 `proposed`；
  6. 目标决策 keep/改选后重新 commit，写 gate；
  7. 追加 `revision` + `audit`；
  8. 任一步失败 → 正文写回原样。
- 无锚点 / hash 不一致 / 正文不可读 → 拒绝，一个字不动。
- 回退后 `beat_segment` 从上一段末尾（真实数据是第 830 字）开始，gate 只授权本次 target 决策。

## 6. 浅色主题字体发白：根因与修复

作者两次反馈右栏字太浅。根因不是字号或亮度，而是**变量名写错**：

- 插件用的是 `--dsw-alias-text-primary` / `--dsw-alias-text-secondary` / `--dsw-alias-border-secondary` / `--dsw-alias-bg-accent`，这些变量在 DSH 里**不存在**。
- DSH 真实的别名 token 是 `--dsw-alias-label-primary/secondary/tertiary`、`--dsw-alias-border-l1/l2`、`--dsw-alias-state-success/warn/error-primary`、`--dsw-alias-bg-base/layer-*/overlay`（可用 Client Theme inspect provider 的 `listTokens` 核对，定义在 `design-platform.css` 的 `body` 与 `body[data-ds-dark-theme]`）。
- 变量缺失 → 全部走兜底的深色写死值（`#e8e9ec` / `#d5d8e1`）；作者是浅色主题，白底上浅灰字实测 **1.21:1**。
- 上一轮的渲染脚本只套了深色 frame、没喂宿主 token，所以截图正常、实机发白。

修复（`client.js`）：

| 位置 | 改动 |
|---|---|
| 根节点变量 | 文字三级接 label-primary / secondary / tertiary；状态色接 state-*；底色接 bg-* |
| 小字状态色 | 新增 `*-ink`：`color-mix(in srgb, 状态色 50–72%, 正文色)`，浅色压暗、深色提亮 |
| 分隔线 / 抬升层 / 软底 | `color-mix` 跟随正文色，不再写死白/黑透明 |
| 类型标签 | 底色 `color-mix(kind 12%)`、描边 36%、文字 55% 混正文色 |
| 旧线正文 | 改用正文色（原来是次要色） |
| 行内样式 | 「拍板：开」按钮、拍板台入口、段落条、错误/提示文字一并换 token |

验证：

- `scripts/render-panel.mjs` 现在按 `design-platform.css` 的真实 light / dark 值注入 token，浅色、深色各渲染决策地图 + 回退确认页 + 旧线。
- 对比度（浅色 / 白底）：正文 18.9:1、次要 5.8:1、注释 3.7:1、ink 小字 6.2–7.3:1；深色：正文 17.4:1、注释 8.5:1。
