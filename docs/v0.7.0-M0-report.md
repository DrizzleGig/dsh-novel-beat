## 二、逐条证据

### 1. guard 作用域与子 agent 继承 —— 不继承，需全局注册

- `dsh-tools/src/index.ts:384` `guard(guard: ToolGuard)` 走 `this.guards.effect(this.ctx, ...)`，即**注册到调用方上下文的作用域**（插件根 ctx = 全局层，`agent.ctx` = 该 agent 层）。
- `dsh-tools/src/index.ts:394-396` `checkGuards()` 遍历 `[this.guards.global, ...this.guards.chainLayers(exec.agent)]`。
- `dsh-scope/src/index.ts:89-98` `scopeParentOf(key)` / `scopeChainOf(key)`：链是"显式 parent 绑定"决定的，最近优先 `[key, parent, …]`。
- `dsh-agent-loop/src/agent.ts:148` `this.scope = createScope(loopCtx, this)` —— **没有传 `parent`**，所以每个 agent 的 scope 都是根，`scopeChainOf(agent)` 只有它自己。
- 推论：`agentCtx.tools.guard(...)` 注册的守卫**只保护该 agent，不保护它派生的子 agent**。

**修正**：L3 改为在插件根 ctx 注册**一个全局 guard**，函数内先判断 `mode`（按 `exec.agent.id`），否则 `return undefined`。这样主会话与子 agent 一律受保护，也免去逐 agent 登记 disposer。能力上等价，且更强。

### 2. 工具内嵌套提问 —— 可行（官方同款）

`dsh-tool-ask-user/src/index.ts:99-110`：

```ts
async execute(args, exec) {
  const result = await ctx.userQuestions.ask({
    questions: args.questions.map(...),
    ...exec.agent !== undefined ? { agent: exec.agent } : {},
    signal: exec.signal,
  })
  …
}
```

- `dsh-user-questions/src/index.ts:291` `ask(request)`；`:299` `assertLiveRoot(agent)`；`:137-148` 只在"不是注册表里的精确存活实例"或"`session.header.origin === 'subagent'`"时才拒（`CALLER_NOT_LIVE` / `DELEGATED_CALLER`）。
- 工具执行体里拿到的 `exec.agent` 正是存活的 Agent 实例，因此 `beat_next` 直接内联提问合法，**不需要**讨论稿里"三步降级"。

### 3. skills 按 agent 层注册/撤销 —— 可行

- `dsh-skill/src/index.ts:439-458` `register(skill)`：`const scope = scopeOf(this.ctx)`，落到该上下文自己的层，返回 disposer。
- `dsh-skill/src/index.ts:556` 读取时 `layers = [this.layers.global, ...this.layers.chainLayers(options.scope)]`。
- 因此 `agentCtx.get('skills').register(SKILL)` → 只有该会话能看到这条技能；disposer 一调即消失。

### 4. systemPrompt.section 的 text 拿得到 agent —— 可以

- `dsh-system-prompt/src/index.ts:66` `readonly text: string | ((context: AssembleContext) => string)`。
- 同文件 `:44-47` `AssembleContext.scope?: ScopeKey`；`:638-639` 组装时按 `chainLayers(scope)` 合并（本作用域优先、可遮蔽全局同名段）。
- agent 的 scope key 就是 agent 实例本身（`createScope(loopCtx, this)`），所以 `text({ scope })` 里 `scope.id` 即 `SessionId`。开关判断可写在该闭包里，`off` 时返回 `''`。
