## 颜色问题：根因与修复（2026-11-17）

作者两次反馈“字体颜色极浅”。第一次只把写死的深色值调亮、字号放大，**没有修好**，因为问题不在亮度，而在变量名：

- 插件写的是 `--dsw-alias-text-primary` / `--dsw-alias-text-secondary` / `--dsw-alias-border-secondary` / `--dsw-alias-bg-accent` 这类名字，**DSH 里根本不存在**。宿主真实 token 是 `--dsw-alias-label-primary/secondary/tertiary`、`--dsw-alias-border-l1/l2`、`--dsw-alias-state-success/warn/error-primary`、`--dsw-alias-bg-base/layer-*/overlay`。
- 变量不存在 → 全部落到兜底值（`#e8e9ec` / `#d5d8e1` 等深色主题色）。作者的 DSH 是浅色主题（白底），于是白底上写浅灰字，实测对比度 **1.21:1**。
- 之前的渲染脚本只套了一层深色 `frame`，宿主 token 一个都没喂进去，所以本地截图看起来正常，实机却发白——**截图环境与宿主不一致**。

修复：

1. 全部换成真实 token；文字分三级（正文 `label-primary`、次要 `label-secondary`、注释 `label-tertiary`）。
2. 状态色（成功/警告/错误）在浅色主题里本身偏亮（`#22c55e` / `#f59e0b`），小字改用 `color-mix` 压向正文色的 ink 版；填充与圆点仍用原色。
3. 分隔线、软底色、抬升层用 `color-mix` 跟随正文色，深浅主题都成立。
4. `scripts/render-panel.mjs` 现在把 `design-platform.css` 里浅色 / 深色两套真实值喂进去，各渲染一张图核对。

浅色主题实测对比度：正文 18.9:1、次要 5.8:1、注释 3.7:1、ok/warn/danger/brand 小字 6.2–7.3:1。
